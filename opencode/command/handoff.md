description: Produce a compact handoff for continuing the current task in a fresh session.
---

Create a self-contained Markdown handoff for a new agent session.

Inspect the current repository state with read-only commands as needed, but do not modify files. Include:

- Objective and user requirements
- Important decisions and constraints
- Work completed
- Current Git status and relevant diff summary
- Relevant files and symbols
- Verification performed and its results
- Remaining work in execution order
- Blockers, risks, and unresolved questions

Keep the handoff concise. Reference files instead of copying their contents. Output only the handoff document.
