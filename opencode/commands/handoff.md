description: Produce a compact handoff for continuing the current task in a fresh session.
---

Create a self-contained handoff document for a new agent session.

Inspect the repository and current state with read-only commands as needed. Do not
modify files. Include, in this order:

1. Objective
2. Constraints
3. Decisions made
4. Completed work
5. Files changed
6. Verification status
7. Known problems
8. Unresolved questions
9. Next concrete action

Keep it concise and reference files rather than copying their contents. Output only
the handoff document.
